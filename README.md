# Legs Mod

## Reject arms, Become Legs

## About

Replace your Gorilla Tag arms with Legs! Legs Mod is a BepInEx mod for the PC version of Gorilla Tag. It changes how your arms and hands look while leaving movement and ground colliders alone.

## Install

1. Download one DLL from the [latest release](https://github.com/PurpleMoonieee-Real/GorillaLegs/releases/latest):
   - `LegsMod.dll` for the standard toggle build.
   - `LegsModAlwaysOn.dll` for the standard always-on build.
   - `LegsModUtilla.dll` for the Utilla toggle build.
   - `LegsModUtillaAlwaysOn.dll` for the Utilla always-on build.
   
   Choose only one DLL. Do not install multiple builds at the same time.
   Both Utilla builds require Utilla 1.5.0 or newer and only work in modded gamemodes.
2. Drop it into `Gorilla Tag/BepInEx/plugins/`.
3. Start Gorilla Tag. BepInEx loads the mod when the game opens.

## What to expect

You can check your own look in a mirror. To see the leg look on friends, they need a compatible build too. Multiplayer visibility is still being tested, so try it with a friend and compare what each of you sees.

The Toggle builds use X on the left VR controller or F8 on keyboard by default. You can change the keyboard key in the BepInEx config. The Always On builds keep the leg look enabled. Version 1.0.9 keeps the same multiplayer markers as 1.0.0, so both versions can recognize each other's leg visuals.

If anything looks off, let us know in the GitHub Issues tab. Have fun!
