# Legs Mod

Give your Gorilla Tag arms a fun, leg-like look! 🦵

## Install

1. Download [`LegsMod.dll`](https://github.com/PurpleMoonieee-Real/GorillaLegs/releases/tag/v1.0.0).
2. Drop it into `Gorilla Tag/BepInEx/plugins/`.
3. Launch the game — no renaming needed!

## Playing with others

For mod-sided visuals, everyone needs a compatible build. Cross-client visibility is still being tested, so grab a friend with the mod to check what each of you can see.
