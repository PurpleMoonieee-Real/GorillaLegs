# Legs Mod

Give your Gorilla Tag arms a fun, leg-like look! Legs Mod is a BepInEx mod for the PC version of Gorilla Tag. It changes how your arms and hands look while leaving movement and ground colliders alone.

## Install

1. Download `LegsMod.dll` from the [v1.0.0 release](https://github.com/PurpleMoonieee-Real/GorillaLegs/releases/tag/v1.0.0).
2. Drop it into `Gorilla Tag/BepInEx/plugins/`.
3. Start the game. No renaming or extra setup needed!

## What to expect

Your client applies the new look locally. For mod-sided visuals, your friends need a compatible build too. Multiplayer visibility is still being tested, so the shared look may not work for everyone yet. Try it with a friend who has the mod installed and compare what each of you sees.

If anything looks off, let us know in the GitHub Issues tab. Have fun!
