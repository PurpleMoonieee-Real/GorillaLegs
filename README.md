# Legs Mod

Give your Gorilla Tag arms a fun, leg-like look! Legs Mod is a BepInEx mod for the PC version of Gorilla Tag. It changes how your arms and hands look while leaving movement and ground colliders alone.

## Install

1. Download `LegsMod.dll` from the [latest release](https://github.com/PurpleMoonieee-Real/GorillaLegs/releases/latest).
2. Drop it into `Gorilla Tag/BepInEx/plugins/`.
3. Start Gorilla Tag. BepInEx loads the mod when the game opens.

## What to expect

You can check your own look in a mirror. To see the leg look on friends, they need a compatible build too. Multiplayer visibility is still being tested, so try it with a friend and compare what each of you sees.

If anything looks off, let us know in the GitHub Issues tab. Have fun!
