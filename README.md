# Legs Mod

Give your Gorilla Tag arms a fun, leg-like look! Legs Mod is a BepInEx plugin for the PC version of Gorilla Tag. It changes how your arms and hands look without changing your movement colliders.

## Install

1. Download `LegsMod.dll` from the [v1.0.0 release](https://github.com/PurpleMoonieee-Real/GorillaLegs/releases/tag/v1.0.0).
2. Drop it into `Gorilla Tag/BepInEx/plugins/`.
3. Start the game. No renaming or extra setup needed!

## Playing with others

Want friends to see the leg look too? Everyone who wants to see it needs a compatible build. Multiplayer visibility is still being tested, so try it with another modded player and check what both of you can see.

Have fun, and share any feedback or bugs in the GitHub Issues tab!
