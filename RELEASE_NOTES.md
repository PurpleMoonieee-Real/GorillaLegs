# Legs Mod v1.0.6

Updated and rebuilt for the latest Gorilla Tag PC update. Visual hands now use local hand-contact data to stay aligned near the floor, with a floor check as backup.

Includes Toggle and Always On builds, with standard and Utilla options. The mod does not alter gameplay colliders. Utilla builds require Utilla 1.5.0 or newer and only work in modded gamemodes.

The multiplayer markers remain compatible with version 1.0.0.
